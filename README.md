A JavaScript script that automates Discord Quest enrollment and progress from the client console.

## Features

- **Auto-accept** — enrolls in available quests automatically.
- **Five task types** — video, mobile video, desktop game, stream, and activity.
- **Parallel processing** — runs multiple quest jobs together.
- **Progress logs** — shows progress and completion messages in the console.
- **Recovery** — retries failed video requests and recreates stalled game or stream activity.

## How to use

1. Open the **Discord desktop app** and sign in.
2. Press **Ctrl + Shift + I** to open Developer Tools, then select **Console**.
3. Open [`discord.js`](./discord.js) and copy the entire script.
4. Paste it into the console and press **Enter**.
5. Follow the progress logs. For stream tasks, start screen sharing in a voice channel.
6. Open the **Quests** page and claim your rewards when available.

The script starts accepting available quests as soon as it runs. No installation or dependencies needed.

**To stop or run again:** reload Discord or close and reopen the app before starting another run.
